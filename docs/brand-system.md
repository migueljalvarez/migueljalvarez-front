# Sistema de marca, tipografía y paleta

Esta guía está pensada para estandarizar los textos, la jerarquía visual y la paleta de color para que el sitio se sienta coherente, premium y profesional.

## 1) Qué atacar primero

### A. Jerarquía tipográfica

El problema más común es que toda la información tiene el mismo peso visual. Es necesario diferenciar claramente:

- titulares principales
- subtítulos
- cuerpo de texto
- etiquetas y formularios
- textos de ayuda
- CTA y acciones

Regla principal:

- El texto más importante debe tener presencia visual clara.
- El cuerpo debe ser legible, tranquilo y cómodo.
- Los textos de apoyo deben ser sutiles, no bajos de contraste ni demasiado claros.

### B. Escala de tipografía recomendada

- h1: 48–64px / 1.1 / 700
- h2: 32–40px / 1.2 / 700
- h3: 24–30px / 1.3 / 600
- h4: 20–22px / 1.4 / 600
- cuerpo: 16–18px / 1.6 / 400–500
- texto secundario: 14–16px / 1.5 / 400–500
- labels: 12–14px / 1.4 / 500–600
- microtexto: 12–13px / 1.5 / 400

### C. Contraste y lectura

Los grises no son “neutrales” si no se gestionan bien. Deben tener un rol claro. Un gris muy claro sobre fondo blanco puede verse bonito, pero no siempre es legible.

La estrategia es:

- fondo blanco o casi blanco para lectura
- textos principales en azul oscuro o negro profundo
- grises para apoyo, labels y placeholders
- no mezclar demasiados grises con la misma luminosidad

## 2) Tu paleta base ya tiene fuerza

Tu base actual es sólida:

- #121E30
- #1C2F4C
- #243B62
- #000000
- #030507

Esto comunica tecnología, solidez y confianza. Lo que falta es equilibrarla con una familia de grises bien pensada para que no se sienta todo oscuro ni todo azul.

### Paleta recomendada

#### Base principal

- #121E30
- #1C2F4C
- #243B62
- #030507
- #000000

#### Neutros complementarios

- #FFFFFF
- #F7F9FC
- #F5F7FA
- #EEF2F7
- #E9EEF5
- #C9D1DC
- #7E8897
- #4D5868
- #1D2430

### Cómo se usa

- #121E30: títulos, jerarquía, bloques visuales fuertes
- #1C2F4C: subtítulos, labels, enlaces o acciones secundarias
- #243B62: CTA principal, foco visual y botón principal
- #030507: texto principal en lectura directa
- #4D5868: texto secundario
- #7E8897: texto auxiliar y placeholders
- #F5F7FA / #F7F9FC: fondos suaves de secciones y paneles
- #E9EEF5: borde y separación sutil
- #FFFFFF: limpieza, cards y inputs

## 3) Sistema para el formulario de contacto

El formulario es una buena referencia porque reúne todos los niveles de texto y color que luego se repiten en la web.

### Propuesta de escala visual

- Título del formulario: 28–32px / 600–700 / #121E30
- Subtítulo: 16–18px / 400–500 / #4D5868
- Label: 12–14px / 500–600 / #1C2F4C
- Input: 16px / 400 / #030507
- Placeholder: 14px / 400 / #7E8897
- Texto de ayuda: 12–13px / 400 / #7E8897
- Botón: 16px / 600 / #FFFFFF sobre #243B62

### Colores del formulario

- Fondo del formulario: #F5F7FA o #FFFFFF
- Input background: #FFFFFF
- Borde input: #E9EEF5
- Focus border: #243B62
- Texto principal: #030507
- Texto secundario: #4D5868
- Label: #1C2F4C
- Placeholder: #7E8897

### Regla importante

- Los títulos son oscuros y claros.
- Los labels tienen un tono ligeramente azulado.
- Los textos auxiliares son grises.
- El botón es el único punto de intensidad fuerte.

Esto hace que el formulario parezca premium, limpio y muy legible.

---

## 4) Regla general para el resto del sitio

Debes mantener esta lógica en toda la interfaz:

- #121E30 y #030507 para la jerarquía principal
- #1C2F4C para apoyo semioficial
- #4D5868 para texto secundario
- #7E8897 para ayuda y metadata
- #243B62 para CTA y elementos de acción
- #F5F7FA y #E9EEF5 para respiración visual y soporte

### Qué no debes hacer

- No usar varios azules distintos como texto normal.
- No poner grises muy claros sobre fondo blanco para texto importante.
- No usar color fuerte en demasiados elementos a la vez.
- No dejar todos los elementos con el mismo peso visual.

---

## 6) Mi recomendación final

Si quieres que la marca se sienta elegante y sólida, la mejor estrategia es esta:

- mantener los azules oscuros como identidad
- usar grises como apoyo visual
- dejar el blanco como limpieza y espacio
- poner el azul fuerte solo en CTAs y acciones claras
- estandarizar texto por nivel visual sin improvisar tamaños

Con esto, el formulario y el resto del sitio hablan el mismo idioma visual.
